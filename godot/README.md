# S.u.G WORLD | Godot comparison branch

Godot 4.x GDScript feasibility scene. Creates ground, lake, forest, cottage, gate, placeholder avatar, camera, fishing and garden actions.

**Not final art.** No approved characters, GLB, iPhone controls, AI, 16-screen navigation or 10-minute gameplay. This is an engine comparison, not a switch of production architecture.

**Not yet verified:** Godot editor import, script parser, headless startup, visual render, iOS export. Do not claim success from file creation.

Run in an available Godot 4.x environment with `godot --headless --path godot --editor --quit`, then inspect in editor. No changes to QUEST, Windows C/D, or the deployed Three.js app.
